# 🚀 Live Demo
🔗 **Live Website:** https://libro-system.vercel.app/

## 📌 Project Overview
**Libro System** is a full-stack Book Management Web Application that allows users to:
- 📖 Upload and manage books
- ⭐ Rate and review books
- 📥 Download book files (PDF)
- 🔐 Secure authentication system
- 🧑‍💼 Role-based access (Admin / User)
- ☁️ Cloud file storage using Cloudinary

This project demonstrates frontend UI design, backend API development, authentication, and cloud storage integration.

## 🛠️ Tech Stack

### 🎨 Frontend
- React.js
- React Router
- Axios
- Context API
- Tailwind CSS / CSS3
- Vercel (Deployment)

### ⚙️ Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cloudinary
- Multer
